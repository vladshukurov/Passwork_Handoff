# Чек-лист передачи

## Что передаётся

| Что | Где |
| --- | --- |
| Исходный код сайта с историей изменений | Git-репозиторий (ветка `main`) |
| Документация | `README.md`, `docs/`, `AGENTS.md` |
| Промты и контекст для нейросетей | `docs/prompts/`, `AGENTS.md`, `docs/ai.md` |
| Описание анимаций и интерактива | `docs/motion.md` |
| Дизайн-система и макет | Figma-файл «Passwork \| Pragmatica», страницы «UI Kit» и «Final» |
| Шрифты, картинки, иконки, иллюстрации | `public/passwork-assets/`, `src/art/illustrations/` |

## Что проверено перед передачей

- [x] Репозиторий клонируется в пустую папку, `npm ci`, `npm test`, `npm run build` проходят.
  Используются только пакеты из публичного registry.npmjs.org.
- [x] В коде нет API-ключей, токенов, `.env` и обращений к внешним сервисам. CSP в
  `vercel.json` запрещает внешние ресурсы.
- [x] Все ассеты, включая шрифты, лежат в репозитории. Внешних CDN нет.
- [x] Нет зависимостей от локальных путей и личных аккаунтов разработчиков. Скрипты
  `scripts/` работают из папки проекта.
- [x] CI (GitHub Actions) выполняет тесты, сборку и `npm audit` без секретов.
- [x] Компоненты Figma лежат в этом же файле. Чужие библиотеки не подключены, иконки и
  логотипы — локальные компоненты.

## Что проверить на своей стороне

- [ ] Репозиторий перенесён в ваш GitHub / GitLab ([git.md](git.md)), ваша команда может
  пушить в `main`.
- [ ] `npm ci && npm run dev` запускается на компьютере вашего разработчика (Node.js 22).
- [ ] Сайт развёрнут в вашем аккаунте Vercel или на вашем хостинге из вашего репозитория.
- [ ] Домен подключён. Адрес в `og:url`, `og:image` и `twitter:image` в `index.html`
  заменён на ваш.
- [ ] Figma-файл перенесён в вашу команду: Share → Move to project или Duplicate. У
  дизайнеров место Full, у разработчиков — Dev или Full.
- [ ] Если нужна работа с нейросетями: у команды свои подписки (Claude Code / Cursor /
  Codex), Figma MCP подключён под вашими аккаунтами ([ai.md](ai.md)).
- [ ] Решено, нужна ли форма заявки с реальной отправкой. Сейчас это прототип
  ([README](../README.md#нестандартные-моменты-и-ограничения)).
